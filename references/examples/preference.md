# Example: Personal Preference Memory

This is what a leaf memory looks like in `~/.loci/life/my-preference/SKILL.md`:

```yaml
---
name: loci-life-my-preference
description: >-
  Personal preferences and work style. Covers tool choices, communication
  style, workflow habits. Use when interacting with the user or configuring
  agent behavior.
---
```

```markdown
# My Preferences

**Last updated**: 2026-03-05
**Source**: User conversation
**Confidence**: high

## Work Style
- Prefers concise, actionable communication
- Wants agents to be proactive with traceable actions

## Tool Preferences
- Editor: VS Code / Cursor
- Shell: zsh with oh-my-zsh

## Change Log
- 2026-03-05: Initial creation from conversation
```
