# Example: Project Context Memory

This is what a leaf memory looks like in `~/.loci/projects/my-app/SKILL.md`:

```yaml
---
name: loci-projects-my-app
description: >-
  My App project context and architecture. TypeScript, React, Node.js stack.
  Use when working on this project or discussing its features.
---
```

```markdown
# My App

**Last updated**: 2026-03-05
**Source**: Project setup session
**Confidence**: high

## Overview
A web application for task management.

## Key Facts
- **Project path**: ~/projects/my-app/
- **Stack**: TypeScript, React, Node.js
- **Repo**: github.com/user/my-app

## Workflow
- Feature branches, PR-based review
- CI runs on push to main

## Change Log
- 2026-03-05: Initial project context
```
